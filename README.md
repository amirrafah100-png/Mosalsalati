# مسلسلاتي

## تشغيل التطبيق (Android Studio)
1. نزّل Android Studio وثبّته.
2. فك ضغط الملف، وبعدين File > Open واختار مجلد Mosalsalati.
3. استنى لحتى يخلص Gradle Sync (بدو إنترنت أول مرة).
4. وصّل موبايلك (مع تفعيل USB debugging) أو أنشئ محاكي، واضغط Run.
5. لملف APK: Build > Build App Bundle(s) / APK(s) > Build APK(s)

## بديل بدون تثبيت (GitHub)
ارفع محتوى المجلد (مع مجلد .github المخفي) لمستودع جديد، وافتح تبويب Actions،
وبعد ما يخلص البناء نزّل mosalsalati-apk.

## تعديل المحتوى
الملف: app/src/main/assets/data.js
حط رابط mp4 مباشر (https) بخانة video لمحتوى إلك أو معك إذن فيه.
روابط يوتيوب ما بتشتغل بهالخانة.
